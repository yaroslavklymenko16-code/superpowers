The co-pilot rule

Claude's terms require users to be 18 or older. So Creator Quest is built for you and your kid together: Claude runs in the Claude Desktop app on your account, connected to Roblox Studio on the same computer. Your kid reads the mission, chooses and edits the prompts, watches Claude build, and does the testing. You send the prompts, click Allow when Claude asks to use a Studio tool, and hold the "stamp" button at the end of each big game.

What you need

  • A Windows PC or Mac. Roblox Studio doesn't run on phones, tablets or Chromebooks.
  • Roblox Studio, free from create.roblox.com.
  • A Roblox account for your kid. Turn on Parental Controls for under-13s.
  • The Claude Desktop app (claude.ai/download), signed in to your Claude account.
  • Studio's built-in connector switched on: Assistant › ⋯ › Manage MCP Servers › Enable Studio as MCP server › Quick connect: Claude Desktop. The warm-up walks you through it.

How building works

Every change is made through Claude. Your kid describes what they want, Claude builds it directly inside Roblox Studio (scripts, parts, models), presses Play to test it, reads the errors and fixes them. No copying or pasting code. Big games are long builds, so a paid Claude plan is smoother; check that your plan supports desktop connectors.

The path: skill quests, then a big game

Unit 0 is a warm-up: install Roblox Studio, find the panels, and run a first script from Claude, with a picture for every click. Then the path has 8 units. Each unit ends with a big game project (45–60 minutes). From Unit 2 on, 3 skill quests (10–15 minutes each) come first and teach what that game needs: detailed models from prompts, leaderboards, floating signs, loops, conveyors, lighting, tools, NPCs, chance tables, tweens, screen GUIs, teleporters, timers, health bars, effects, boss design, terrain, game design and publishing. A skill quest is a short lesson: learn it, try one prompt in Studio, answer one question. Short quests are great for school nights.

Each big game has 5 stages

1. AI BrainA short lesson about how AI works, plus a 2-question quiz. Read it together.
2. BuildSetup checklist, the Mega Prompt (one prompt that makes Claude build a whole game system in Studio, test it and fix it), and a "test it" checklist.
Explain itYour kid asks Claude to explain how the game works, you read the answer together, and they answer one question about it.
3. Boss Bug"Spot Claude's mistake": a short piece of code with one broken line. Your kid taps it.
4. Power-upsExtra prompts that add features. Kids pick what sounds fun.
5. FinishA conversation question for you, then you hold the stamp button.

When things go wrong

Troubleshooting

ProblemFix
Claude can't see StudioIn Studio: Assistant › ⋯ › Manage MCP Servers. Make sure "Enable Studio as MCP server" is on and the green light shows a connected client. Update Studio, then restart both Studio and Claude Desktop. Studio and Claude must be on the same computer.
The MCP Servers option isn't thereUpdate Roblox Studio to the latest version. Some Studio AI features can depend on the signed-in account; if you can't find it on your kid's account, try signing in to Studio with your own Roblox account.
Claude keeps asking for permissionThat's normal: Claude asks before using a Studio tool. Click Allow. Claude Desktop may offer to remember the choice for the session.
Something in the game doesn't workUse the "fix prompt" in the Build stage: say what you did and what happened. Claude reads Studio's Output for errors, fixes the script and playtests again.
Claude stopped halfwayType "continue". If the connection dropped, check the green light in Studio and send the prompt again.
We've tried three fixes and it's still brokenSend the "backup prompt" from the Build stage. Claude swaps in a ready-made version of the whole game.
Two games are mixing togetherEach big game should be its own place. Start a new Baseplate for each one.
Adding Vault modelsIn the app's Vault, tap "Ask Claude to add it" and send the prompt: Claude builds the model into your place. Or insert a whole pack yourself from the optional extras download (unzip it first). Then right-click Workspace › Insert from File and browse to the Creator Vault folder.
Creator Quest progress disappearedProgress is saved in the browser you used. Use the same browser on the same computer, and don't use a private window.

Online safety

  • Publish games as Private or Friends only at first (Game Settings on create.roblox.com).
  • Keep Roblox Parental Controls on for under-13s.
  • Mission 6 teaches never to share full name, school, address or passwords with AI or in game chat.
  • Claude stays on your account in the desktop app. Your kid doesn't need their own.
