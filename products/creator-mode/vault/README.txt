CREATOR VAULT · 118 Roblox models
=================================

EASIEST: ASK CLAUDE
In Creator Quest, open the Vault, pick a model and tap "Ask Claude to add it".
Send the prompt in Claude Desktop and Claude builds the model into your open place.

OR ADD A WHOLE PACK YOURSELF
1. Open your game in Roblox Studio.
2. In the Explorer, right-click Workspace.
3. Choose "Insert from File...".
4. Pick a pack, for example "Creator Vault - Nature.rbxmx".
5. The whole pack appears in a row. Move the models you want. Delete the rest.

- Spooky (9): tombstones, pumpkin, coffin, cauldron, skull, iron fence, zombie spawner

- Game Systems (3): talking NPC, mini tycoon kit, speed shop pad

SCRIPTED MODELS
46 models have a Script inside and work as soon as you press Play.
Open the Script to change the settings at the top (speed, power, prices...).
Or copy the script into Claude and ask it to change something!

TIPS
- Recolor anything: select a part, change Color in Properties.
- Need more checkpoints? Copy one and rename it "Checkpoint 4", "Checkpoint 5"...
- Every pet, coin and checkpoint can be copied as many times as you want.
- Want even more? Roblox Studio's Toolbox (View > Toolbox) has millions of free models.

All Creator Vault models were made for Creator Mode. Use them in any game you make, including games you publish.
